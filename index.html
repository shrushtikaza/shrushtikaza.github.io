Adaptive Post-Quantum Secure Fund Transfer System Using Blockchain and Machine Learning

Conventional cryptography such as Rivest–Shamir–Adleman (RSA) and Elliptic Curve Digital Signature Algorithm (ECDSA) is susceptible to quantum attacks, hence the need for post-quantum cryptography (PQC). This study presents a Substrate blockchain-based fund transfer system with adaptive cryptography enabled by machine learning (ML) and Cryptographic Suite for Algebraic Lattices (CRYSTALS)-Dilithium for quantum-secure signatures. The LightGBM classifier is used to dynamically choose Dilithium variants (II, III, V) depending on runtime performance, and the Isolation Forest is used to identify fraud and attacks. The results indicate that ECDSA is 50% faster in total execution time (6s vs. 9s), but Dilithium-III is 18 times faster in verification (0.07 ms vs. 1.26 ms) with quantum security. The system demonstrates efficient signing for integrating PQC with Artificial Intelligence (AI) for next-generation financial security.
